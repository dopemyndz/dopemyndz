WHATSAPP
--------
Open script.js and replace:
const WHATSAPP_NUMBER = "234XXXXXXXXXX";

with your real WhatsApp number.
For Nigeria, 08012345678 becomes 2348012345678.

NOTE
----
The current account system uses browser localStorage. It is suitable for a simple
static website/demo, but it is NOT secure server-side authentication. For real
customer accounts across devices, use a backend such as Supabase or Firebase.
